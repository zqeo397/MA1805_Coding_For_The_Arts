The emoji I made is heavily inspired by something my father loves, 
Bubble Bobble, specifically Bub (From the video game)

-- Theme --
Simply recreating Bub would be boring, so the plan is a Halloween theme.
So, Devil horns, Fangs.

-- What I learned / Issues I ran into --

Towards the end, I found it really annoying having to type 250, 350, etc., for the transforms.
Which is when I did some research and found out about - push + pop -
This let me set a selected bit of code to have its own transform and be adjustable without affecting the transforms of the rest of the Emoji.

Using Scale, Translate and Rotate was also a lifesaver when it came to the Hands and Feet,
As it stopped me from needing to do maths to figure out what numbers to punch in so the hands/feet look as if they're facing a specific way.

The most difficult bit by far was figuring out the locations specific parts of Bub need to be, for example, if the Body came after the head, the head would be behind the body. Took a rather large amount of trial and error to get this correct,
